# Design quality bar

1. Aim for a **clean, modern mobile UI**: spacing, hierarchy, alignment, and consistent type scale.
2. HarmonyOS-like aesthetics are **optional inspiration** (rounded cards, soft neutrals, clear primary accent), but **not mandatory** unless the user asks.
3. Use a **single primary accent** and neutral surfaces; avoid rainbow gradients unless the payload is inherently colorful (e.g., charts) or the user requests it.
4. Provide **clear hierarchy**: title → summary/meta → primary content → secondary details.
5. Interactions (tabs, filters, expand/collapse) should be **simple and robust**; prefer minimal JS.
